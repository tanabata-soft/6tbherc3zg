# 全長版の音源（保管用）

v1.6.0 でアプリ収録曲を「音ゲー用ショート編集」（イントロ→1番→サビで終わる編集版）に
差し替えたため、元の全長版をここに保管する。アプリには含まれない
（`src/assets/` にある編集版だけが import され、dist に入る）。

- `highway.mp3`: 『石畳のハイウェイ』全長版（179.6秒）
- `night.mp3`: 『Kiso Night Silhouette』全長版（179.9秒）
- `gospel.mp3`: 『谷底にも朝が来る』全長版（263.3秒。v1.9.3 で追加）
- `kira.mp3`: 『キラキラ木曽旅』全長版（211.6秒。v1.9.3 で追加）

gospel / kira の出所は、最初に提供された単体HTML版
（`~/workspace/user/files/kiso-rhythm-game_0_1l6e.html`）に埋め込まれていた
MP4（Opus 音声＋mov_text 字幕）。このフォルダのファイルは、その音声を
MP3 192kbps に変換したもの。字幕は HTML 側に残っているので、歌詞の再抽出は
`scripts/extract-lyrics.py` が HTML から直接行う。

編集版の作り方（ffmpeg、編集版は `src/assets/`）:

- highway: 0〜104.756秒（小節59頭まで＝サビ1終了＋間奏4小節）を残し、
  最後の2.0秒（102.756秒〜）にフェードアウト。合計 104.76秒
- night: 0〜127.730秒（小節80頭まで＝サビ2終了）を残し、
  最後の1.6秒（126.130秒〜）にフェードアウト。合計 127.73秒
- gospel: 0〜125.50秒（サビ1の最終行が終わる小節の頭まで）を残し、
  最後の1.6秒（123.90秒〜）にフェードアウト。合計 125.50秒。
  サビ1の直後に2番が始まるため、間奏を足す余地はなくこの形にした
- kira: 0〜118.24秒（2番の最終行が終わる小節の頭まで）を残し、
  最後の1.6秒（116.64秒〜）にフェードアウト。合計 118.24秒。
  2番の後に歌入りのサビが無い（ブリッジへ進む）ため、night 型
  （1番＋サビ＋2番）の区切りとしてここで終える

全長版に戻すときは、このフォルダのファイルを `src/assets/` へ戻し、
`scripts/generate-charts.py` の FEVER 区間を全長版の値に戻して譜面を再生成する。
全長版の FEVER（サビ区間。字幕のサビ位置＋小節 RMS から特定）:

- highway [[57, 96], [144, 174]] / night [[44, 67], [96, 128], [140, 164]]
- gospel [[100, 124], [202, 222]] / kira [[64, 90], [157, 183]]

なお、単体HTML版に埋め込まれていた FEVER 定数（gospel [[82, 92], [159, 172],
[186, 218]] / kira [[129, 192], [197, 210]]）は、サビ1を含まないなど
サビ位置と対応していなかったため採用しなかった（PWA 版の FEVER は
「サビ＝FEVER」の意味で統一している。v1.9.3）。
